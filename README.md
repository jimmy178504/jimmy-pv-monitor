# Jimmy PV Monitor

Jimmy PV Monitorは、WordPressサイトのPV（ページが表示された回数）を計測する日本語のアクセス解析プラグインです。

解析データは、利用しているWordPressのデータベース内に保存されます。Jimmyや外部の解析サービスへ解析データを送信しません。

## ダウンロード

- [Jimmy PV Monitor Free 0.5.13](download/jimmy-pv-monitor-0.5.13-final.zip)

WordPressへインストールするときは、ZIPを解凍せず、そのままアップロードしてください。

## 主な機能

- 今日、過去3日、過去7日、過去30日、任意期間のPV確認
- ページごとの期間PVと累計PV
- 日別PVの折れ線グラフ
- 検索、SNS、外部サイトなどの流入元確認
- 記事内にある外部リンクやアフィリエイトリンクのクリック確認
- 今日・昨日・過去7日・今月のPVをWordPressダッシュボードへ表示
- CSV出力
- `[jimmy_pv]`による累計PVの公開表示
- 標準365日間のデータ保存

同じブログ内でのページ移動は、流入元には含めません。

## 動作条件

- WordPress 6.7以上
- PHP 8.1以上
- MySQL 5.7以上、またはMariaDB 10.4以上
- WordPressシングルサイト
- HTTPS推奨

WordPressマルチサイトには対応していません。

## インストール

1. WordPress管理画面へログインします。
2. 「プラグイン」→「新規プラグインを追加」を開きます。
3. 「プラグインのアップロード」を押します。
4. ダウンロードしたZIPを選びます。
5. 「今すぐインストール」→「プラグインを有効化」の順に押します。
6. 左側メニューの「Jimmy PV」を開きます。

詳しい操作方法は[利用ガイド](docs/USER-GUIDE.md)をご覧ください。

## 初回確認

初期設定では、管理者としてログイン中の閲覧はPVから除外されます。動作確認は、シークレットウィンドウまたはログアウトしたブラウザーで公開記事を表示して行ってください。

## 累計PVの公開

記事本文やショートコード対応ウィジェットに次のショートコードを置きます。

```text
[jimmy_pv]
```

100PV以上の場合だけ表示する例です。

```text
[jimmy_pv min="100"]
```

PVは自動では公開されません。

## Pro版について

Pro版では、期間内で重複しない訪問者数、訪問回数、記事から記事への移動、訪問全体の流れ、記事別導線、外部サイトへの離脱を確認できます。

Pro版はFree版とは別に配布するため、この公開リポジトリにはPro版ZIPを含めません。

## データとプライバシー

Free版は、PV・ページ情報・ブラウザーから提供された参照元・外部リンククリックをWordPressのデータベースへ保存します。訪問者を識別するCookie、IPアドレス、氏名、メールアドレスはFree版の解析データとして保存しません。

サイト運営者は、自身の利用方法と適用されるルールに合わせてプライバシーポリシーを整備してください。
