# Jimmy PV Monitor

Jimmy PV Monitorは、WordPressサイトのPV（ページが表示された回数）を計測する日本語のアクセス解析プラグインです。

解析データは、利用しているWordPressのデータベース内に保存されます。Jimmyや外部の解析サービスへ解析データを送信しません。

## 主な機能

- 今日、昨日と今日の2日間、過去3日・7日・10日・30日・50日・100日・200日・365日、任意期間のPV確認
- ページごとの期間PVと累計PV
- 選択期間にかかわらず常に確認できる今日のPV
- 日別PVの棒グラフとリンククリックの折れ線
- 直近7日間とその前の7日間を比べた、最近PVが増えた記事・減った記事
- 検索、SNS、外部サイトなどの流入元確認
- ページ別PV、リンククリック数、日別推移、クリックされたリンクを確認できるページ詳細
- アフィリエイトリンク、外部リンク、内部リンクに分けた、クリック先ドメイン単位のクリック確認
- PVに対するクリック率、クリック種類の構成、よく押されたリンクの視覚的な比較
- PVとクリック率をサイト平均と比べる記事改善マップ、流入元の構成、クリック種類別の推移
- 今日・昨日・過去7日・今月のPVをWordPressダッシュボードへ表示
- CSV出力
- `[jimmy_pv]`による累計PVの公開表示
- 標準365日間のデータ保存

スマートフォンでは、レポート表を列名と値が分かるカードとして画面幅内に表示し、上部の画面切り替えも横スクロールせず全項目を確認できます。Free／Proダッシュボードの棒グラフも画面幅に合わせて縮小します。

同じブログ内でのページ移動は、流入元には含めません。

## 動作条件

- WordPress 6.7以上
- PHP 8.1以上
- MySQL 5.7以上、またはMariaDB 10.4以上
- WordPressシングルサイト
- HTTPS推奨

WordPressマルチサイトには対応していません。

## インストール

1. WordPress管理画面へログインします。
2. 「プラグイン」→「新規プラグインを追加」を開きます。
3. 「プラグインのアップロード」を押します。
4. ダウンロードしたZIPを選びます。
5. 「今すぐインストール」→「プラグインを有効化」の順に押します。
6. 左側メニューの「Jimmy PV」を開きます。

操作方法は、目的に合わせて次の説明書をご覧ください。

- [完全マニュアル](docs/COMPLETE-MANUAL.md)
- [トラブル対応・復旧マニュアル](docs/TROUBLESHOOTING-AND-RECOVERY.md)

## 初回確認

初期設定では、管理者としてログイン中の閲覧はPVから除外されます。動作確認は、シークレットウィンドウまたはログアウトしたブラウザーで公開記事を表示して行ってください。

## 累計PVの公開

記事本文やショートコード対応ウィジェットに次のショートコードを置きます。

```text
[jimmy_pv]
```

100PV以上の場合だけ表示する例です。

```text
[jimmy_pv min="100"]
```

PVは自動では公開されません。

## Pro版について

Pro版では、匿名Cookieで同じブラウザーだと確認できた閲覧を期間内で重複させない訪問者数、訪問回数、記事から記事への移動、訪問全体の流れ、記事別導線、外部サイトへの離脱を確認できます。別の端末・ブラウザーやCookie削除後は別の訪問者として数えます。Proダッシュボードでは日別UVとPro表示回数を棒グラフで比較し、終了した訪問が1ページで終わったか2ページ以上見られたかも構成グラフで確認できます。記事別導線では、選んだ記事を中心に直前・直後のページと、その後の結果を視覚的に確認できます。Pro画面の記事名は記事別導線の詳細へ進み、記事本体は近くにある「公開ページへ」から開きます。

Pro 0.1.35では、記事別導線とAI改善分析の記事選択をタイトルの一部から検索できます。記事別導線と全体の内部導線は、画面内リンクで目的の項目へ移動しながら、すべての分析を1ページで確認できます。全体の内部導線は代表的な訪問経路を導線マップとして強調し、同じ経路を下の一覧へ重複表示しません。AI改善分析では集計データの分析に加え、公開中の記事本文をAIに確認させ、検索意図、構成、読みやすさ、根拠、内部リンク、収益導線などを率直にレビューさせる準備ファイルも作成できます。

Pro版はFree版とは別に配布します。Free版・Pro版のどちらもGitHubには配布用ZIPを置かず、[Jimmy PV Monitor ダウンロードページ](https://jimmy-blog.com/jimmy-pv-monitor/)で案内します。

Pro 0.1.35を使用する場合は、先にFree 0.5.28へ更新して有効化してください。

## データとプライバシー

Free版は、PV・ページ情報・ブラウザーから提供された参照元・記事本文内のリンククリックをWordPressのデータベースへ保存します。訪問者を識別するCookie、IPアドレス、氏名、メールアドレス、ページをまたいだ訪問経路はFree版の解析データとして保存しません。

サイト運営者は、自身の利用方法と適用されるルールに合わせてプライバシーポリシーを整備してください。
