# Jimmy PV Monitor サイト向けプライバシー説明文案

- 更新日: 2026-08-21
- 対象: Jimmy PV Monitor 0.5.14 / Jimmy PV Monitor Pro 0.1.13
- 用途: サイト運営者が自サイトのプライバシーポリシーへ反映するための編集用文案

> この文案は一般的な説明用であり、法的助言ではありません。実際の設定、利用目的、保存期間、対象地域の法令、Cookie同意管理に合わせて編集し、必要に応じて専門家へ確認してください。使用していない機能の段落は削除してください。

## 無料版だけを使う場合の文案

### アクセス解析について

当サイトでは、サイトの利用状況を把握し、コンテンツを改善するため、「Jimmy PV Monitor」を使用しています。

この機能は、ページの閲覧日時、閲覧されたページ、ページタイトル、ブラウザーから提供された参照元URL、UTMキャンペーン情報、記事本文内にあるサイト内・外部リンクの表示とクリックを、当サイトのWordPressデータベースへ保存する場合があります。同じサイト内でのページ移動は流入元として保存しません。無料版のクリック計測はリンクが押された事実を集計しますが、ページをまたいだ訪問順序や移動前後のつながりは保存しません。参照元URLは、認証情報、フラグメント、および当サイトが指定した機微なクエリ項目を除去してから保存します。ブラウザーの設定や参照元ポリシーにより、参照元URLの一部または全部を取得できない場合があります。

無料版のアクセス解析では、訪問者を識別するCookieや永続的なブラウザーストレージを使用せず、IPアドレス、氏名、メールアドレス、WordPressユーザーIDを解析データとして保存しません。また、解析データをJimmyまたは第三者の解析サーバーへ送信しません。

分析用の日別データの保存期間は標準365日です。当サイトの実際の設定が異なる場合は、ここを「○日」に変更してください。ページの累計PVは、当サイトが削除操作を行うまで保持される場合があります。

## Pro版も使う場合に追加する文案

### 匿名の訪問者数と閲覧経路について

当サイトでは、匿名の訪問者数、セッション、サイト内の閲覧順序、入口ページ、推定離脱ページを把握するため、「Jimmy PV Monitor Pro」を使用する場合があります。

Pro版が有効な場合、匿名訪問者と処理中セッションのためのファーストパーティCookieを使用します。Cookieにはランダムな識別子を保存し、WordPressデータベースにはサイト固有の鍵で変換した値を保存します。Cookieの生値、IPアドレス、氏名、メールアドレス、WordPressユーザーIDをPro解析データへ保存せず、解析データをJimmyまたは第三者の解析サーバーへ送信しません。

匿名訪問者Cookieの標準有効期間は365日、セッションの標準終了判定は最後のページ表示から30分です。分析用集計データの標準保存期間は365日です。当サイトの実際の設定が異なる場合は、それぞれ実際の値へ変更してください。

外部サイトへのリンクがクリックされた場合は明示的な離脱として記録することがあります。次のページ表示がない場合は、一定時間後に最後に閲覧したページから離脱したものと推定します。複数タブ、通信失敗、Cookieの拒否または削除などにより、実際の行動と異なる場合があります。

## 同意モードを使う場合に追加する文案

Pro版のCookieを同意後だけ使用する設定の場合は、次のような説明をサイトの同意管理方法に合わせて追加してください。

> 匿名訪問者数と閲覧経路を計測するCookieは、利用者がアクセス解析Cookieへ同意した後にだけ設定されます。同意前または同意撤回後はPro版による匿名訪問者・セッション計測を行いません。Cookieの選択は、当サイトのCookie設定画面から変更できます。

「Cookie設定画面」の表現やリンク先は、実際に導入した同意管理機能に合わせて変更してください。通常モードでPro版を使う場合、この段落をそのまま使用しないでください。

## 運用時の確認事項

- 実際の管理画面設定と説明文の保存期間を一致させる。
- Pro計測を無効にしている場合は、Pro版の段落を掲載しない。
- Pro版を同意モードで使う場合は、同意管理側からProの同意APIを正しく呼ぶ。
- 参照元URLやUTMへ個人情報を入れないよう、広告・メール・フォーム運用も確認する。
- サイトのデータ削除、バックアップ、問い合わせ対応の手順を決める。
- WordPressの「設定 > プライバシー」に表示されるプラグイン提案文も確認する。

## 実装との対応

| 説明項目 | 無料版 | Pro版 |
|---|---|---|
| PV | 保存 | 無料版の値を利用 |
| 参照元・UTM | 保存 | セッション流入にも利用 |
| 記事本文内のリンククリック | サイト内・外部を保存 | 外部サイトへの離脱としても別集計する場合がある |
| 訪問者Cookie | 使用しない | 有効時に使用 |
| IPアドレス | 解析データへ保存しない | 解析データへ保存しない |
| 匿名UV・セッション | 対象外 | 保存・集計 |
| 周遊経路・入口・離脱 | 対象外 | 保存・集計 |
| Jimmy側への解析送信 | しない | しない |
