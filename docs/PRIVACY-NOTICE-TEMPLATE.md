# Jimmy PV Monitor サイト向けプライバシー説明文案

- 更新日: 2026-09-11
- 対象: Jimmy PV Monitor 0.5.22 / Jimmy PV Monitor Pro 0.1.30
- 用途: サイト運営者が自サイトのプライバシーポリシーへ反映するための編集用文案

> この文案は一般的な説明用であり、法的助言ではありません。実際の設定、利用目的、保存期間、対象地域の法令、Cookie同意管理に合わせて編集し、必要に応じて専門家へ確認してください。使用していない機能の段落は削除してください。

## 無料版だけを使う場合の文案

### アクセス解析について

当サイトでは、サイトの利用状況を把握し、コンテンツを改善するため、「Jimmy PV Monitor」を使用しています。

この機能は、ページの閲覧日時、閲覧されたページ、ページタイトル、ブラウザーから提供された参照元URL、UTMキャンペーン情報、記事本文内にあるサイト内・外部リンクの表示とクリックを、当サイトのWordPressデータベースへ保存する場合があります。同じサイト内でのページ移動は流入元として保存しません。無料版のクリック計測はリンクが押された事実を集計しますが、ページをまたいだ訪問順序や移動前後のつながりは保存しません。参照元URLは、認証情報、フラグメント、および当サイトが指定した機微なクエリ項目を除去してから保存します。ブラウザーの設定や参照元ポリシーにより、参照元URLの一部または全部を取得できない場合があります。

無料版のアクセス解析では、訪問者を識別するCookieや永続的なブラウザーストレージを使用せず、IPアドレス、氏名、メールアドレス、WordPressユーザーIDを解析データとして保存しません。また、解析データをJimmyまたは第三者の解析サーバーへ送信しません。

分析用の日別データの保存期間は標準365日です。当サイトの実際の設定が異なる場合は、ここを「○日」に変更してください。ページの累計PVは、当サイトが削除操作を行うまで保持される場合があります。

## Pro版も使う場合に追加する文案

### 匿名の訪問者数と閲覧経路について

当サイトでは、匿名の訪問者数、セッション、サイト内の閲覧順序、入口ページ、推定離脱ページを把握するため、「Jimmy PV Monitor Pro」を使用する場合があります。

Pro計測がオンの場合、同意操作を待たずに匿名訪問者と処理中セッションのためのファーストパーティCookieを使用します。Cookieにはランダムな識別子を保存し、WordPressデータベースにはサイト固有の鍵で変換した値を保存します。Cookieの生値、IPアドレス、氏名、メールアドレス、WordPressユーザーIDをPro解析データへ保存せず、解析データをJimmyまたは第三者の解析サーバーへ送信しません。

匿名訪問者Cookieの標準有効期間は365日、セッションの標準終了判定は最後に確認できた閲覧から30分です。画面が表示されている間は一定間隔で閲覧中であることを記録し、ページを離れるときにも最後の時刻の記録を試みます。分析用集計データの標準保存期間は365日です。当サイトの実際の設定が異なる場合は、それぞれ実際の値へ変更してください。

外部サイトへのリンクがクリックされた場合は明示的な離脱として記録することがあります。次のページ表示がない場合は、一定時間後に最後に閲覧したページから離脱したものと推定します。複数タブ、通信失敗、Cookieの拒否または削除などにより、実際の行動と異なる場合があります。

### AI改善分析機能を使用する場合

Pro版のAI改善分析機能は、サイト全体または特定記事の集計データと公開URLを含むファイルを、サイト管理者の操作で作成します。プラグインが解析データをAIサービスへ自動送信することはありません。サイト管理者が作成したファイルを外部AIサービスへ添付した場合、そのファイルに含まれる集計値と公開URLは、選択したAIサービスへ送信されます。

分析ファイルには、個人を特定する情報や読者ごとの閲覧履歴を含めません。AIサービスの利用条件、保存、学習利用、共有設定などは各サービスによって異なるため、サイト管理者は使用前にその取り扱いを確認します。AIが公開記事へアクセスした場合、その閲覧が当サイトのPV、流入元、サイト内移動として記録されることがあります。

AI改善分析を使用しない場合、この段落は削除してください。

## 旧版から更新する場合

Pro 0.1.29以降では、旧版の「同意後だけ計測」の設定が残っていても、Pro計測がオンなら同意通知を待たずに計測します。「同意した後にだけCookieを使用する」という旧説明を掲載している場合は、現在の動作に合わせて更新してください。明示的な外部連携の停止通知は引き続き受け付けます。

## 運営者が記入する項目

- 利用目的: 例「記事改善、導線改善、障害調査」
- 無料版の日別データ保存期間: `_____日`
- Pro集計データ保存期間: `_____日`
- Pro計測: `使用する / 使用しない`
- ProのCookie利用方法: `計測オンの場合は同意通知を待たずに使用`
- AI改善分析: `使用する / 使用しない`
- 使用する外部AIサービス: `____________________`
- データに関する問い合わせ先: `____________________`
- 適用開始日・最終更新日: `____________________`

## 運用時の確認事項

- 実際の管理画面設定と説明文の保存期間を一致させる。
- Pro計測を無効にしている場合は、Pro版の段落を掲載しない。
- 旧版の同意待ちに関する説明が残っていないか確認する。
- 参照元URLやUTMへ個人情報を入れないよう、広告・メール・フォーム運用も確認する。
- サイトのデータ削除、バックアップ、問い合わせ対応の手順を決める。
- WordPressの「設定 > プライバシー」に表示されるプラグイン提案文も確認する。

## 実装との対応

| 説明項目 | 無料版 | Pro版 |
|---|---|---|
| PV | 保存 | Cookieを利用できるPro計測対象の表示回数を別集計 |
| 参照元・UTM | 保存 | セッション流入にも利用 |
| 記事本文内のリンククリック | サイト内・外部を保存 | 外部サイトへの離脱としても別集計する場合がある |
| 訪問者Cookie | 使用しない | 有効時に使用 |
| IPアドレス | 解析データへ保存しない | 解析データへ保存しない |
| 匿名UV・セッション | 対象外 | 保存・集計 |
| 周遊経路・入口・離脱 | 対象外 | 保存・集計 |
| Jimmy側への解析送信 | しない | しない |
