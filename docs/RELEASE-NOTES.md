# Jimmy PV Monitor 更新履歴

この文書は、GitHub上の説明書が対応している主な更新内容をまとめたものです。

配布用ZIPはGitHub上では公開していません。Free版・Pro版ともに、最新の配布案内とZIPのダウンロードは[Jimmy PV Monitor ダウンロードページ](https://jimmy-blog.com/jimmy-pv-monitor/)をご確認ください。

## 現在の対応バージョン

- Jimmy PV Monitor Free 0.5.24
- Jimmy PV Monitor Pro 0.1.31

Pro版を使用するには、先にFree版0.5.14以降をインストールして有効化する必要があります。

## Free 0.5.24 / Pro 0.1.31

### Free 0.5.24

- クリック計測の一覧を、リンク文字や個別URLではなくクリック先ドメインごとの1行へ変更
- 各ドメインの内訳で、詳細なクリック先URL、リンクの文字、リンクが掲載されているページ、クリック総数、掲載ページのPV、PVに対するクリック率、最終クリック日時を表示
- 「アフィリエイトリンク」「外部リンク」「内部リンク」のクリック数付きカードを種類の切り替え操作として残し、役割が重複していた下段のタブを削除
- 保存済みのクリックデータと設定はそのまま引き継ぎ、データベース変更なしで表示時にドメイン単位へ集計

### Pro 0.1.31

- Proダッシュボードの日別UVとPro表示回数を、2本の棒グラフで比較する表示へ変更

PHP 8.1／8.3、MySQL 8.0、MariaDB 10.11でドメイン集計と内訳を検証し、両データベースで1万PV分の連続書き込み試験も実施しています。同時アクセス数やすべてのサーバー構成での性能を保証するものではありません。

## Free 0.5.23 / Pro 0.1.31

### Free 0.5.23

- ダッシュボードで、どの集計期間を選んでも「今日のPV」を常に表示
- 日別PV推移を折れ線から棒グラフへ変更
- 昨日までの直近7日間と、その前の7日間を比較する「最近のPV変化」を追加
- 5PV以上かつ50%以上変化したページを、増加・減少それぞれ最大5件まで表示。該当がなければ無理に5件を表示しない仕様
- ページ別PVへ横棒、リンククリック数、ページ詳細へのリンクを追加
- ページ詳細で、選択期間のPV、累計PV、リンククリック総数、PVに対するクリック数、日別PV、実際にクリックされたリンクを確認できるように変更
- クリック計測を「アフィリエイトリンク」「外部リンク」「内部リンク」の3種類へ分け、種類別のクリック数を表示
- クリック先のリンクごとに1行でまとめ、内訳からクリック元ページとページ詳細を確認できるように変更
- 既に記録済みのクリックも、リンク先URLから判定できる範囲で3種類に分類して表示

### Pro 0.1.31

- Proダッシュボードの日別UVとPro表示回数を、2本の棒グラフで比較する表示へ変更

データベース構造は変更していません。保存済みのPV、クリック、Pro計測データ、設定は更新後も引き継がれます。PHP 8.1／8.3、MySQL 8.0、MariaDB 10.11で基本動作を確認し、1万PV分の連続書き込み試験も実施しています。同時アクセス数やすべてのサーバー構成での性能を保証するものではありません。

## Pro 0.1.30

- 送信元情報（Origin）がない計測リクエストで発生するPHP非推奨警告を修正
- PHP 8.1／8.3の基本テストと構文チェックに合格
- WordPress 7.0.2／MySQL 8.0.46で旧同意設定からの計測を検証：同意通知なしでPV 2・訪問者数1、計測オフ後は追加記録なし
- 導線・保存期間・アンインストールと1万PV分の連続DB書き込みを検証し、警告・エラーなしを確認（同時アクセス数の試験ではありません）

Free版の更新は不要です。更新には0.1.29ではなく0.1.30を使用してください。

## Pro 0.1.29

- Pro計測がオンの場合、同意通知を待たずにCookieを利用して計測する仕様へ変更
- 旧「同意した後だけ計測」設定も同じ動作へ変更
- Cookieモードの選択欄を説明表示へ変更し、画面とプライバシー説明を更新
- 計測オン・オフ、保存済みデータ、Cookie保存不可時の停止、外部連携からの明示的な停止通知は維持

Pro計測は初期状態ではオフです。「Jimmy PV」→「Pro 設定」で「訪問者数と、同じ訪問中のページ移動を計測する」をオンにして保存してください。Pro 0.1.29以降は同意通知を待たず、Cookieを利用して計測します。旧版の「同意した後だけ計測」設定も更新後は同意を待たない動作になります。既存の計測オン・オフと保存済みデータは引き継がれます。Cookieを保存できないブラウザーはPro計測の対象外です。

## Pro 0.1.19

- 「AI改善分析（Pro）」画面を追加
- サイト全体の回遊、入口、離脱、サイト内リンク、外部・アフィリエイトリンクをまとめたMarkdownファイルを作成
- 1記事を選び、その記事のPV、前後の移動、訪問のきっかけ、記事内リンクのクリックをまとめたMarkdownファイルを作成
- ChatGPT、Claude、Gemini、Perplexityを開くボタンを追加
- AIボタンを押すと分析ファイルがダウンロードされ、選んだAIが別画面で開く仕組みを追加
- AIによる記事閲覧がPV等へ含まれる可能性、AI画面でのファイル添付が必要なこと、外部AIサービスへファイル内容が送信されることを管理画面で説明
- 分析ファイルへ、記事内リンク・広告・フォームを操作しない指示と、記事本文内の命令文に従わないための指示を追加

分析ファイルは作成時にそのままダウンロードされます。WordPress内に公開ページ、一時URL、保存ファイルは作りません。また、プラグインからAIサービスへの自動送信やAI APIの呼び出しは行いません。既存の解析データと設定は引き継がれ、データベース構造の変更もありません。

## 更新時の注意

1. 更新前にWordPressのファイルとデータベースをバックアップしてください。
2. Free版を先に更新し、その後にPro版を更新してください。
3. ZIPは解凍せず、そのままWordPress管理画面からアップロードしてください。
4. 更新後は、シークレットウィンドウまたはログアウトした状態で計測を確認してください。

問題が起きた場合は[トラブル対応・復旧マニュアル](TROUBLESHOOTING-AND-RECOVERY.md)をご確認ください。
