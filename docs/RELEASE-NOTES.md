# Jimmy PV Monitor 更新履歴

この文書は、GitHub上の説明書が対応している主な更新内容をまとめたものです。

配布用ZIPはGitHub上では公開していません。Free版・Pro版ともに、最新の配布案内とZIPのダウンロードは[Jimmy PV Monitor ダウンロードページ](https://jimmy-blog.com/jimmy-pv-monitor/)をご確認ください。

## 現在の対応バージョン

- Jimmy PV Monitor Free 0.5.15
- Jimmy PV Monitor Pro 0.1.20

Pro版を使用するには、先にFree版0.5.14以降をインストールして有効化する必要があります。

## Free 0.5.15

- WordPressダッシュボードの「Jimmy PV サマリー」をカード形式へ変更
- 今日のPVに、昨日との差を表示
- 過去7日と今月のPVに、1日平均を表示
- 今日の人気記事上位10件に、順位、PV数、記事同士の差が分かる横棒を表示
- 詳細ダッシュボードとページ別PVへのボタンを表示

集計方法やデータベース構造は変更していないため、既存のPV、クリックデータ、設定は引き継がれます。

## Pro 0.1.20

- ChatGPT、Claude、Gemini、Perplexityのボタンを押したとき、分析用ファイルのダウンロードとAI画面の表示に加えて、貼り付け用の依頼文をクリップボードへコピー
- AI画面でファイルを添付したあと、WindowsではCtrl＋V、Macではcommand＋Vで依頼文を貼り付ける手順へ変更
- 管理画面でコピーされる依頼文を事前に確認できる表示を追加
- ブラウザーが自動コピーに対応していない場合の手動コピー案内を追加
- AIサービスのURLには依頼文や解析データを含めず、依頼文を自動送信しない設計を維持

既存の解析データと設定は引き継がれ、データベース構造の変更もありません。

## Pro 0.1.19

- 「AI改善分析（Pro）」画面を追加
- サイト全体の回遊、入口、離脱、サイト内リンク、外部・アフィリエイトリンクをまとめたMarkdownファイルを作成
- 1記事を選び、その記事のPV、前後の移動、訪問のきっかけ、記事内リンクのクリックをまとめたMarkdownファイルを作成
- ChatGPT、Claude、Gemini、Perplexityを開くボタンを追加
- AIボタンを押すと分析ファイルがダウンロードされ、選んだAIが別画面で開く仕組みを追加
- AIによる記事閲覧がPV等へ含まれる可能性、AI画面でのファイル添付が必要なこと、外部AIサービスへファイル内容が送信されることを管理画面で説明
- 分析ファイルへ、記事内リンク・広告・フォームを操作しない指示と、記事本文内の命令文に従わないための指示を追加

分析ファイルは作成時にそのままダウンロードされます。WordPress内に公開ページ、一時URL、保存ファイルは作りません。また、プラグインからAIサービスへの自動送信やAI APIの呼び出しは行いません。既存の解析データと設定は引き継がれ、データベース構造の変更もありません。

## Pro 0.1.18

- 「訪問者・訪問状況（Pro）」にある「最初に見られたページ」「最後に見られたページ」「訪問のきっかけ」を、ほかのレポートと同じ表形式へ統一
- ページ名や訪問のきっかけと訪問回数を、それぞれ独立した列で表示
- 「最後に見られたページ」では、「このページで終わった割合」を独立した列で表示
- 各表の意味が分かる短い説明を追加

集計方法やデータベース構造は変更していないため、既存の解析データと設定は引き継がれます。

## Pro 0.1.17

- Proダッシュボードの「多かった訪問全体の流れ」を、ほかのダッシュボード項目と同じシンプルな表形式へ統一
- 見られたページの順番、訪問のきっかけ、訪問の終わり方、訪問回数、平均表示ページ数を表示
- ページ名から、そのページを選択した記事別導線へ移動できる機能を維持
- 過剰だった順位の丸印、ボタン状のページ名、色付きラベルを削除

集計方法やデータベース構造は変更していないため、既存の解析データと設定は引き継がれます。

## Pro 0.1.15

- 記事別導線の「外部サイトへの離脱」で、最終クリック日時を表示すると重大なエラーになる問題を修正
- 「Pro離脱回数」を「このリンクで訪問が終わった回数」へ変更
- リンク文字やURLが極端に狭く表示されないよう表幅を調整

## Pro 0.1.14

- 記事別導線の「外部サイトへの離脱」に、リンクの文字、クリック先、クリックがあった表示、クリック総数、訪問終了回数、最終クリック日時を追加
- Free版のクリック数とPro版の訪問終了回数が異なる集計であることを画面内で説明

## Free 0.5.14

- 「外部リンククリック」を「クリック計測」へ変更
- 記事本文内のサイト内リンク、外部リンク、アフィリエイトリンクをクリック対象として計測
- クリックした事実だけをFree版に記録し、訪問中のページ移動や順序の解析はPro版に限定
- 既存の外部リンククリックデータと設定を引き継ぎ

## 更新時の注意

1. 更新前にWordPressのファイルとデータベースをバックアップしてください。
2. Free版を先に更新し、その後にPro版を更新してください。
3. ZIPは解凍せず、そのままWordPress管理画面からアップロードしてください。
4. 更新後は、シークレットウィンドウまたはログアウトした状態で計測を確認してください。

問題が起きた場合は[トラブル対応・復旧マニュアル](TROUBLESHOOTING-AND-RECOVERY.md)をご確認ください。
