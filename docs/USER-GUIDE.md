# Jimmy PV Monitor Free 0.5.27 利用ガイド

このガイドは、WordPressやアクセス解析に詳しくない方でも操作できるように、専門用語をできるだけ避けて説明しています。

## 0. ZIPの入手

配布用ZIPはGitHub上では公開していません。Free版・Pro版ともに、最新の配布案内とZIPのダウンロードは[Jimmy PV Monitor ダウンロードページ](https://jimmy-blog.com/jimmy-pv-monitor/)をご確認ください。

ダウンロードしたZIPは解凍せず、そのままWordPressへアップロードします。

## 1. インストール後に確認すること

1. WordPress管理画面の「Jimmy PV」→「設定」を開きます。
2. 「PV計測を有効にする」がオンになっていることを確認します。
3. トップページも計測する場合は「トップページを計測」をオンにします。
4. 「日別データ保存日数」が365日になっていることを確認します。
5. 「設定を保存」を押します。
6. シークレットウィンドウで公開記事を表示します。
7. 少し待ってから「Jimmy PV」→「ダッシュボード」を確認します。

管理者としてログイン中の閲覧は、初期設定ではPVに含まれません。

## 2. 画面の見方

### ダッシュボード

サイト全体の状況を確認する画面です。

- 今日のPV
- 選択期間のPV（「今日」以外を選んだ場合）
- 昨日との比較
- 指定期間の1日平均との比較
- 日別PVの棒グラフ
- 最近PVが増えた記事・減った記事
- よく見られているページ
- 検索、SNS、外部サイトなどの流入元概要

初期表示期間は「今日」です。ほかの期間を選んでも、今日のPVは常に画面上部へ表示されます。棒グラフへマウスを合わせると、その日のPVを確認できます。

「最近のPV変化」は、今日を除く直近7日間と、その前の7日間を比較します。5PV以上かつ50%以上変化した記事を、増加・減少それぞれ最大5件まで表示します。条件に当てはまる記事がなければ「大きく変化した記事はありません」と表示します。

### ページ別PV

記事やトップページごとのPVを確認します。選択期間にPVが0件のページは表示しません。

- 選択期間のPVと、ページ同士の差が分かる横棒
- 選択期間のリンククリック数
- 累計PV
- サイト全体のPVに占める割合

ページ名を押すと「ページ詳細」を開きます。ページ詳細では、選択期間のPV、累計PV、リンククリック総数、PVに対するクリック数、日別PVの棒グラフ、実際にクリックされたリンクをまとめて確認できます。

### 流入元

読者が検索サイト、SNS、他のWebサイトなど、どこから訪れたかを確認します。

同じ流入元は1行にまとめられています。「最初に見られたページの内訳を表示」を押すと、その流入元から最初にどのページが見られたかを確認できます。

同じブログ内でのページ移動は流入元に含めません。ブラウザーから参照元が提供されなかった場合は「直接・不明」になります。

「UTM・広告からの流入」では、広告やSNS投稿へ付けた識別情報を確認できます。

### クリック計測

記事本文にあるサイト内リンク、外部リンク、アフィリエイトリンクが押された回数を確認します。選んだ期間に実際にクリックされたリンクだけが表示されます。

画面上部のクリック数付きカードで、次の3種類を選びます。

- アフィリエイトリンク
- 外部リンク
- 内部リンク

クリック先のドメインごとに1行で表示し、クリック先URL数、クリック元ページ数、クリック総数、最終クリック日時を確認できます。「URL・リンク文字・掲載ページを表示」を押すと、詳細なクリック先URL、リンクの文字、リンクが掲載されているページ、ページごとのクリック数とPVに対するクリック率を確認できます。掲載ページ名を押すと、そのページの「ページ詳細」へ移動します。

アフィリエイトリンクは、対応しているASPや短縮URLなどをリンク先URLから判定します。判定できないリンクは「外部リンク」として表示される場合があります。更新前から保存されているクリックも、リンク先URLから判定できる範囲で分類されます。

更新前のクリックには正確な日時が保存されていないため、「更新前のため記録なし」と表示される場合があります。

この画面はクリックした事実だけを集計します。同じ訪問中にどの記事からどの記事へ移動したかという順序や、移動前後のつながりはPro版の「内部導線」または「記事別導線」で確認します。

### CSV出力

次のデータを、Excelなどで開けるCSVファイルとして保存できます。

- 日別PV
- ページ別PV
- 流入元別PV
- UTM・広告PV
- クリック計測

## 3. 期間の選択

期間を選択できる画面では、次の期間を使用できます。

- 今日
- 過去3日（今日を含む）
- 過去7日
- 過去30日
- 任意期間

選んだ期間は、ほかの期間指定画面へ移動しても引き継がれます。

## 4. WordPressダッシュボード

通常のWordPressダッシュボードには、次の情報を表示できます。

- 今日のPV
- 昨日のPV
- 過去7日間のPV
- 今月のPV
- 今日の人気記事 上位10件

Free 0.5.15以降では、4つのPVをカード形式で表示します。今日のカードでは昨日との差を確認でき、過去7日と今月のカードでは1日平均も確認できます。人気記事にはPV数に応じた横棒が表示されるため、記事同士の差を見比べやすくなっています。

Free 0.5.21以降では、スマートフォンのレポート表を、列名と値が分かる画面幅内のカードとして表示します。上部の画面切り替えも折り返して全項目を表示するため、横へスクロールする必要はありません。Free 0.5.22以降では、ダッシュボードの日別PVグラフもスマートフォンの画面幅に合わせて縮小します。Free 0.5.23以降は日別PVを棒グラフで表示します。

「詳細レポートを見る」からJimmy PVのダッシュボードへ、「ページ別PVを見る」からページ別レポートへ移動できます。

表示したくない場合は、「Jimmy PV」→「設定」でダッシュボードウィジェットをオフにできます。

## 5. 累計PVを記事へ表示する

### 基本

```text
[jimmy_pv]
```

### 100PV以上の場合だけ表示

```text
[jimmy_pv min="100"]
```

### 特定の記事のPVを表示

```text
[jimmy_pv post_id="123"]
```

### 表示文を変える

```text
[jimmy_pv format="この記事は{count}回見られました"]
```

使用できる文字は次のとおりです。

- `{count}`: 桁区切りされたPV
- `{count_raw}`: 桁区切りなしのPV
- `{title}`: 記事タイトル

## 6. 主な設定

### PV計測を有効にする

オフにすると新しいPVの記録を止めます。保存済みデータは残ります。

### 計測するページ

投稿、固定ページ、トップページ、カテゴリーなどの記事一覧、サイト内検索結果、404ページについて、計測するかを選べます。

### 除外するログイン権限

チェックした権限でログイン中の閲覧をPVから除外します。自分の確認操作を数えないため、管理者は除外したままがおすすめです。

### 参照元URLを保存する

オンにすると、読者がどこから訪れたかをブラウザーから提供された範囲で保存します。同じブログ内のページ移動は保存しません。

### 日別データ保存日数

初期値は365日です。期限を過ぎた日別データは削除されますが、記事の累計PVは残ります。

### アンインストール時に全データを削除

オンにしてプラグインを削除すると、解析データも完全に削除されます。通常はオフがおすすめです。プラグインを無効化しただけではデータは削除されません。

## 7. 更新方法

1. 念のためWordPressのファイルとデータベースをバックアップします。
2. [Jimmy PV Monitor ダウンロードページ](https://jimmy-blog.com/jimmy-pv-monitor/)から新しいZIPをダウンロードします。
3. 「プラグイン」→「新規プラグインを追加」→「プラグインのアップロード」を開きます。
4. 新しいFree版ZIPを選択します。
5. 現在のバージョンを置き換える操作を実行します。

通常の更新では、保存済みのPVや設定は引き継がれます。

## 8. PVが増えないとき

次の点を確認してください。

- 「PV計測を有効にする」がオンか
- 管理者としてログインしたまま確認していないか
- 対象の記事やページが一般公開されているか
- キャッシュやセキュリティ対策がWordPressの計測通信を止めていないか
- ブラウザーの広告ブロック機能が通信を止めていないか

まずはシークレットウィンドウで公開記事を表示し、数分後に今日のPVを確認してください。

## 9. Pro版との違い

Free版はPV、流入元、記事本文内のリンククリックを中心に確認します。Pro版では、次の内容を追加で確認できます。

- 期間内で同じ人を重複して数えない訪問者数
- 1回の訪問で見られたページ数や時間
- 記事から記事への移動
- 訪問全体で見られたページの順番
- 記事ごとの直前・直後のページ
- 外部サイトへの離脱
- サイト全体または1記事のデータを、普段使っているAIで確認するための分析ファイル作成

Pro版を使用する場合も、Free版を先にインストールして有効化しておく必要があります。

Pro計測は初期状態ではオフです。「Jimmy PV」→「Pro 設定」で「訪問者数と、同じ訪問中のページ移動を計測する」をオンにして保存してください。Pro 0.1.29以降は同意通知を待たず、Cookieを利用して計測します。旧版の「同意した後だけ計測」設定も更新後は同意を待たない動作になります。既存の計測オン・オフと保存済みデータは引き継がれます。Cookieを保存できないブラウザーはPro計測の対象外です。

Pro 0.1.17以降のProダッシュボードでは、「多かった訪問全体の流れ」を、ほかの一覧と同じ表形式で確認できます。ページの順番、訪問のきっかけ、訪問の終わり方、訪問回数、平均表示ページ数が表示され、ページ名から記事別導線へ移動できます。

Pro 0.1.18以降の「訪問者・訪問状況（Pro）」では、「最初に見られたページ」「最後に見られたページ」「訪問のきっかけ」も表形式で確認できます。ページ名や訪問のきっかけと訪問回数が列ごとに分かれ、「最後に見られたページ」では、そのページで訪問が終わった割合も確認できます。

Pro 0.1.21以降では、画面が表示されている間とページを離れるときにも閲覧中の時刻を記録し、1ページだけの訪問や最後のページの時間が短く出やすい状態を改善しています。UVは実在する個人の人数ではなく、匿名Cookieで同じブラウザーだと確認できた閲覧を重複させない値です。

Pro 0.1.23以降のProダッシュボードでは、日別UVとPro表示回数を同じグラフで確認できます。Pro 0.1.27以降はスマートフォンのPro表と上部タブが画面幅内に収まり、Pro 0.1.28以降はグラフも横スクロールせず確認できます。Pro 0.1.31以降は、日別UVとPro表示回数を2本の棒グラフで比較します。

Free 0.5.25以降のダッシュボードとページ詳細では、青い棒でPV、オレンジ色の線でリンククリック数を同じ日別グラフに表示します。クリックの種類別構成、PVに対するクリック率、よくクリックされたリンクも、数字だけでなく色分けした図や横棒で比較できます。

Pro 0.1.32以降のProダッシュボードでは、終了した訪問のうち「2ページ以上見られた訪問」と「1ページで終わった訪問」の割合を構成グラフで確認できます。記事別導線では、選んだ記事を中央に置き、よく見られた直前・直後のページと、その記事のあとに回遊・訪問終了・外部サイト移動のどれが起きたかを視覚的に確認できます。

Free 0.5.26以降では、ページ別PVに「記事改善マップ」、ページ詳細にサイト平均との比較と流入構成、流入元に構成図、クリック計測に種類別の推移を表示します。最初に図で傾向をつかみ、下の表で正確なURLや件数を確認できます。

Pro 0.1.33以降では、訪問者・訪問状況、全体の内部導線、記事別導線にも順位バーや訪問経路カードを追加しています。選択した記事は経路内で強調されるため、その記事へ来る前と見た後の動きを追いやすくなります。

Pro 0.1.34以降では、各分析画面の上部に期間内の特徴を示す「分析ポイント」を表示します。訪問のきっかけの構成、訪問者からページ移動までの行動概要、よく起きたページ移動を図で確認し、下の表で正確な件数を確認できます。Pro画面の記事名を押すと、その記事を選択した「記事別導線（Pro）」へ移動します。記事本体を開く場合は、記事名の近くにある「公開ページへ」を押してください。

### AI改善分析（Pro 0.1.19以降）

「Jimmy PV」→「AI改善分析（Pro）」を開き、「サイト全体を分析」または「1つの記事を分析」を選びます。ChatGPT、Claude、Gemini、Perplexityのボタンを押すと、分析用のMarkdownファイルがダウンロードされ、貼り付け用の依頼文がコピーされ、選んだAIが別画面で開きます。

開いたAIへダウンロードされたファイルを添付し、WindowsではCtrl＋V、Macではcommand＋Vでコピー済みの依頼文を入力欄へ貼り付けて送信してください。安全上の理由により、WordPressからAI画面へファイルを自動添付したり、入力欄へ直接書き込んだりすることはできません。

Pro 0.1.21以降では、AIへ渡す依頼文が最初から画面に表示されます。内容は目的に合わせて編集でき、「標準の依頼文に戻す」でいつでも初期状態へ戻せます。

AIが公開記事を確認すると、その閲覧がPV、流入元、サイト内移動として記録される場合があります。また、ファイルをAIへ添付すると、その内容は選んだAIサービスへ送信されます。利用前に、そのサービスの利用条件とデータの取り扱いを確認してください。
